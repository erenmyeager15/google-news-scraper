## 60-Second Tutorial Script

1. Open the Actor and keep the default `artificial intelligence` keyword.
2. Set `maxArticlesPerFeed` to 5 for a tiny first run.
3. Run the Actor and open the dataset table.
4. Show title, source, publish time, snippet, query, country, and language fields.
5. Export to CSV or connect the dataset URL to an alerting or summary workflow.
